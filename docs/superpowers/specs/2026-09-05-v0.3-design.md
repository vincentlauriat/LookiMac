# v0.3 — Design & Plan (compact)

Date: 2026-09-05 · Status: approved by Vincent ("oui vas y" on the proposed order) · Branch `feat/v0.3`
Source of truth for the API: `docs/api/looki-memory-SKILL.md`.

## Scope (in this order)
1. **Fix journal pagination**: `GET /journals?cursor_date=&max_days=&sort_order=` (app sent `cursor_id`). `max_days` 31 (max) per page.
2. **All clips of a moment**: `GET /moments/{id}/files?highlight&cursor_id&limit` (limit max 100).
   - Model: `MomentFile` gains `thumbnail: RemoteFile?`; `RemoteFile` gains `size: Int?`; `FilesPage { items, nextCursorId, hasMore }`.
   - Client: `momentFiles(id:highlight:cursor:limit:)` and `allMomentFiles(id:highlight:)` (follows cursor, max 10 pages).
   - Detail view: under the player, a grid of clip thumbnails (frame grabbed like covers, cached by file id); clicking a clip plays it; badge "N clips · H highlights".
   - Archive: per moment, download **every** file into `<HHmm-id8>/<index03>-<fileid8>.<ext>` (index by created_at), cover no longer downloaded separately; `moments.json` unchanged. New `ArchiveEvent.expanded(additional: Int)` raises the progress total as files are discovered. Skip existing non-empty files.
3. **Month marks in one call**: `GET /moments/calendar?start_date&end_date` → `[CalendarDay { date, highlightMoment: MomentSummary? }]`. `refreshMonthMarks` does one request for the visible month (clamped to today), marks present days (count 1) and absent past days (0); cache counts still override when known. Journal mode: `GET /journals/calendar` marks days with posts.

## Out of scope
Realtime widget, search date filters, `/me` email/region (v0.4 candidates).
