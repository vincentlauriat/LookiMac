A small, fast SwiftUI app talking to the Looki Open API, read-only. Metadata and thumbnails are cached locally so reopening is instant; videos stream from Looki when you press play.Une app SwiftUI petite et rapide qui parle à l'API ouverte de Looki, en lecture seule. Métadonnées et vignettes sont mises en cache localement pour une réouverture instantanée ; les vidéos sont lues en streaming depuis Looki.小巧快速的 SwiftUI 應用程式，以唯讀方式呼叫 Looki 開放 API。中繼資料與縮圖在本機快取，重新開啟即時可用；影片在按下播放時從 Looki 串流。

Reviewing them on a phone screen is fine; reading a whole day, searching a year, keeping your own copy calls for a Mac. Looki pour Mac is that window: three columns, a search field, and an archive button.La Looki L1 filme de courts clips toute la journée et les transforme en moments titrés, décrits et géolocalisés. Les revoir sur un téléphone, très bien ; relire une journée entière, chercher dans une année, garder sa propre copie appelle un Mac. Looki pour Mac est cette fenêtre : trois colonnes, un champ de recherche et un bouton d'archive.Looki L1 整天拍攝短片，並把它們變成有標題、有描述、有地點的時刻。在手機上回看很好；但重讀整整一天、搜尋一整年、保留自己的副本，需要一台 Mac。Looki pour Mac 就是那扇窗：三個欄位、一個搜尋框、一個封存按鈕。

how it workscomment ça marche運作方式

From the cloud to a folder you controlDu cloud à un dossier que vous contrôlez從雲端到你掌控的資料夾

Looki keeps your moments online. The app reads them with your personal API key, caches what makes browsing fast, and writes a durable copy only when you ask for it.Looki garde vos moments en ligne. L'app les lit avec votre clé API personnelle, met en cache ce qui rend la navigation rapide, et n'écrit une copie durable que lorsque vous le demandez.Looki 把你的時刻放在雲端。應用程式用你的個人 API 金鑰讀取，快取讓瀏覽變快的部分，並且只在你要求時才寫入一份持久副本。
